### 📡 [amiibo-reader](https://github.com/p-beger/amiibo-reader)

*Bibliothèque Python de lecture de figurines amiibo via RFID.*

- Lecture de tags NFC NTAG215 avec un lecteur MFRC522.
- Identification des amiibo à partir de leurs données et d'une base locale.
- Gestion des tags inconnus et des erreurs de lecture.
- Communication avec le lecteur via SPI.

**Stack :** Python 3.13, MFRC522, SPI, Raspberry Pi.

### 🎵 [amiibo-music-player](https://github.com/p-beger/amiibo-music-player)

*Lecteur musical sur Raspberry Pi piloté par des figurines amiibo.*

- Association d'une figurine à une sélection musicale.
- Lecture aléatoire des morceaux correspondant à la figurine détectée.
- Gestion de la détection et du retrait des tags NFC.
- Démarrage automatique du lecteur via systemd.
- Prise en charge de bibliothèques musicales locales et sur clé USB.

**Stack :** Python 3.13, Raspberry Pi, MFRC522, mpg123, systemd.
